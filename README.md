# COMPLETE-JAVA-LABS

Welcome to my Java repository! In this project, I have solved many programming questions to build and improve my core logic.

My main focus is to make my programming logic strong, so I have created all these codes using pure core logic and loops.

## 📂 Project Structure

I have divided my code into separate packages to keep everything organized:

* **`pkg01_basics`**: Contains basic Java programs like Variables, Operators, and If-Else conditions.
* **`pkg02_patterns`**: Contains more than 30 different types of logic patterns and number pyramids (such as Diamond, Palindrome Triangles, and Circular Rotation Matrix).
* **`pkg03_logical_questions`**: Contains standard interview programs based on mathematical algorithms, loop optimizations, and edge-case handling (like Fibonacci, Reverse, Binary/Decimal, and Armstrong numbers).
* **`pkg04_string`**: Contains essential String programs like Palindrome checks, printing all Substrings, and Reversing words.
* **`pkg05_arrays`**: Contains foundational Array operations, and Searching and Sorting methods.
